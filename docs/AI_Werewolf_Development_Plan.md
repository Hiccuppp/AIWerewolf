# AI Werewolf Development Plan

## Phase 1: Web-based Werewolf Simulator

### Goal
Build a functional Werewolf simulation game with a Web UI.

### Scope
- **Features:** 3 fixed game modes, full game loop, role abilities, `RandomPlayer` implementation.
- **Automation:** Automated game execution, logging system.
- **Web UI:** Viewable logs and game status in a Web UI.
- **Excluded:** LLMs, Prompts, Observer Agents, Voice Analysis, Room/Matchmaking systems, Infinite role expansion.

### Development Roadmap
- [ ] D001: Project Initialization
- [ ] D002: Data Modeling
- [ ] D003: Game Loop Implementation
- [ ] D004: Role Abilities
- [ ] D005: Random Player Implementation
- [ ] D006: Web UI
- [ ] D007: Testing & Verification
